如何获取 / 复制浏览器 Cookie？

方式 A（推荐，免粘贴）：在本机电脑浏览器（Chrome / Edge / Brave）登录目标平台（腾讯视频、快手、B站、抖音等），app 解析时会自动读取该浏览器的登录 Cookie，无需手动粘贴。

重要 · 自动获取的边界：自动读取的是电脑浏览器的登录态，与以下两者互不通用：① 手机 App 的登录态（在手机上，电脑读不到）；② 其他独立账号体系（如某些网盘 / 客户端）的登录态（与视频平台账号互不相通）。因此手机分享出来的链接，需先在电脑浏览器登录对应平台（如用手机快手 App 扫码登录 kuaishou.com）后，才能自动带上 Cookie 解析成功。

方式 B（手动复制，用于 Safari / Firefox、指定账号、或自动读取失败）：

  1. 浏览器打开并登录目标站点（如 v.qq.com）。
  2. 按 F12（Mac：⌘+⌥+I）打开开发者工具 → Application（应用） → 左侧 Cookies → 选站点域名 → 复制整列 Cookie 值；
    或切到 Console（控制台） 输入 document.cookie 复制整串。
  3. 把复制到的字符串粘贴到上方「会话 Cookie」文本框。

Cookie 仅用于本次解析/下载，服务端不留存；VIP 账号需保持订阅有效才能拿到高画质。
